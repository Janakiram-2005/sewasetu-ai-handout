External MCP Client Connectivity & Setup Guide

Configure Claude Code, Cursor, or any Streamable HTTP MCP client to connect to Sewa Setu.

1. Endpoints

AudienceEndpoint URLRequired ScopeTransport
Citizen Assistant {{ issuer }}/mcp/citizen citizen Streamable HTTP POST & SSE
Block Officer Assistant {{ issuer }}/mcp/officer officer Streamable HTTP POST & SSE

2. Authentication Flows

  • OAuth 2.1 Interactive Sign-in: Clients register at /oauth/register and initiate PKCE authorization at /oauth/authorize?scope=citizen (verified with OTP) or scope=officer (verified with departmental password).
  • Unattended Program Tokens: Officers generate long-lived RS256 Bearer JWTs at /admin/tokens.
  • Bearer Token Header: Attach token to MCP requests via Authorization: Bearer <access_token>.

3. Claude Code / MCP Client Configuration Example

{
  "mcpServers": {
    "sewasetu-citizen": {
      "url": "{{ issuer }}/mcp/citizen",
      "headers": {
        "Authorization": "Bearer <CITIZEN_TOKEN>"
      }
    },
    "sewasetu-officer": {
      "url": "{{ issuer }}/mcp/officer",
      "headers": {
        "Authorization": "Bearer <OFFICER_TOKEN>"
      }
    }
  }
}
